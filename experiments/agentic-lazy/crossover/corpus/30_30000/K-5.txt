KNOWLEDGE K-5 -- Search index rebuild notes

For a leaf service with no consumers, only steps 1, 2 and 5 apply; the rollback rehearsal is calibrated for changes that other teams pin. Tags in the mirror can be re-pointed when the upstream tag moves, so reproducible builds pin by digest. Write the description as three explicit sections: what changes, why now, and what you deliberately did not change. Re-running the suite with a randomised order and with the suspect test isolated distinguishes these two worlds cheaply. A checklist with step 3 skipped is a deploy, not a release, and should be labelled as such in the announcement. If the lockfile diff is large and surprising, that is itself the finding, not churn to ignore. The reviewer asks no question that the description already answers, and the review has fewer rounds than the same author's previous change. Each segment is sealed when it reaches a size target and a new segment is opened. Pin the dependency set and commit the lockfile.
