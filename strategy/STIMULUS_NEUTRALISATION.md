## 2. What was applied, and the tag family

- **Exercise:** byte-substring replacement of the ten tokens, case-sensitive, **longest-first** so
  `ToolCallIR.` is handled before `ToolCallIR` and `role.canRequestEscalation` before
  `canRequestEscalation`. Injective; a consistent, single-token rename.
- **Scope of the rewrite:** every file in the copy that contained a token — `fixture/fixture-190.json`,
  `fixture/reflex-decisions.ts`, all five `results/eval-*.json`, `results/baselines.json`, and the four
  generated second-labeller artefacts (regenerated by the tools, not hand-edited).
- **Generated artefacts were regenerated with the package's own tools,** never edited:
  `parse_fixture.py` rewrote `cases.json`, `blinded_cases.json`, `parse_summary.json`; `compare.py`
  rewrote `metrics.json`, `disagreements.jsonl`.
- **Tag family:** `NC01`…`NC10` — NEUTRAL-TAG/v1 class-prefixed ordinals.

**Why the package's own gate grammar accepts it.** The package's positive gate
(`scratch/ugate1/gate_scoped.sh:72-76`) declares released id grammars, one of which is
`^[NKFS][A-Z]?[0-9]{2,4}$`. `NC01` = `N` + `C` + `01` matches that grammar, so the gate reads each tag as
**declared released-id vocabulary**, not as an out-of-vocabulary mechanism token — the failure mode that
made the ten original tokens gate hits. The tag is also `^[A-Za-z][0-9]{2,}$`, which the scorer's
`TOKEN = re.compile(r"[a-z0-9]+")` (`second-labeller/compare.py:19`) reads as **exactly one token**, so a
rename cannot split one scored token into several (the mechanism that moved `routeA.ties` in earlier work,
`strategy/CODE_AGNOSTIC_RELEASE_POLICY.md` §B.3). No `NC`-family token existed in the package before
(grep: 0).

### U6's structural explanation is REFUTED by isolation
U6 wrote: “route A is a tokeniser-overlap heuristic, and a consistent injective single-token rename preserves which
tokens are distinct.” Measured on a pristine copy, re-running `compare.py` for each subset:
- **dotted four alone** (`test.run`, `memory.write`, `web.fetch`, `role.model`) reproduce the entire route A movement:
  kappa `0.31988636363636364`, agreement `0.3368421052631579`, pe `0.024930747922437674`, exact_index `64`, ties `118`.
- **hyphenated four alone** (`memory-curator`, `code-inspector`, `code-review`, `output-only`) leave route A's
  kappa/agreement/pe/exact_index unchanged but move **ties** `120` → `123`.
- **all eight**: exact_index `64`, ties `121` — non-additive in `ties`.
Mechanism: route A's own rule string is “distinct-token overlap + 0.5 substring bonus, argmax, ties->lowest index”
(`PREREGISTRATION.md` §2). Token-set overlap is rename-invariant **only for tokens the tokeniser keeps whole**; a token
containing `.` or `-` is not kept whole, so its fragments still contribute to the overlap and to the character-level
substring bonus. Replacing an 8-character dotted token with a 4-character tag dropped one exact match into a tie.
U6's *observation* (its own ten tokens moved nothing) stands; its *generalisation* does not — invariance was a property
of those ten tokens in those cases, not of the class.
