# U1.4 — Close the ingestion coverage gap

**Status:** done · **Bound:** ≤30 tool calls, 0 LLM calls, ≤2 Occamy probes (used 1) · **Commits:** none

## Purpose
Find exactly which files in a target repo the knowledge graph *actually* ingests and
which it silently skips, then make the highest-value skipped types (notebooks,
JSONL/CSV research data) ingestible as markdown. The tool's promise is "extract any and
all research-related material"; a silently dropped file can never become a finding and
nothing in the pipeline would ever say it was missing.

## Design notes
- **Real machinery, no second list.** Ignore decisions reuse
  `graphify.detect.ignored_predicate` (`.graphifyignore` + `.gitignore` chains +
  `$GIT_DIR/info/exclude` + git tracked-file exemption); classification uses
  `graphify.detect.classify_file` and its real extension sets; dir pruning reuses
  `_is_noise_dir` and `_SKIP_FILES`. Nothing executes repository code.
- **Version fact worth knowing:** this graphify (0.9.80) has **no `FileType.OFFICE`** —
  `.docx`/`.xlsx` classify as `DOCUMENT` (supported). `.json` is in `CODE_EXTENSIONS`,
  so it *is* ingested; `.jsonl`, `.csv`, `.tsv`, `.ipynb`, `.tex`, `.bmp`, `.xml`,
  `.rels` are in no set and are dropped.
- **Bounded by construction:** `MAX_OUTPUT_BYTES` 4 MiB, `MAX_IMAGE_BYTES` 2 MiB,
  JSONL sample 200 / table 50 / scan 100 000, CSV table 50 / scan 100 000. JSONL and
  CSV stream line by line and stop at the scan cap, so a 500 MB file cannot be slurped.
  The caps in force are recorded in every output as `<!-- bounds: ... -->`.
- **Never raises:** malformed notebooks return a typed `ipynb-error` NormalizedFile with
  the parse error and no output; bad roots return an empty report with a note.
