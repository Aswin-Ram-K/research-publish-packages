## §6 What you should NOT do

- **GraphRAG / code-graph-rag / potpie / blarify** — same parse→graph→cluster as `graph.json`, plus a DB service; GraphRAG's README says "largely in maintenance mode". You would operate a server to recompute what you already have.
- **semgrep / Joern / CodeQL** — taint/dataflow depth no claim here needs; CodeQL's CLI is under proprietary terms and its DB build is minutes-to-hours per commit. A second graph schema is a drift source, not a second opinion.
- **zoekt / Sourcebot / Sourcegraph** — many-repo search *servers*; the payoff needs 10⁷+ lines or many users, and Sourcegraph needs a licence key. The "repo not publicly retrievable (API 404)" line is **withdrawn**: S2's own handoff records the 404 as the label applied after the unauthenticated GitHub API was rate-limited, so it says nothing about the repo (CORRECTIONS.md C5).
- **repomix / gitingest / code2prompt** — they move token cost and destroy node identity, so `file:line` provenance cannot survive; the claim gets re-located anyway.
- **Serena** — GPL-3.0-or-later **and** no MCP client mounted, so it cannot be reached; two blockers for a fidelity gain you don't yet need.
- **Understand / Sourcetrail** — paid/proprietary; archived five years ago with a per-language indexer UI.
- **Graft** — writes `graft/`, an `AGENTS.md` block and editor hooks into the target; the read-only rule is not negotiable. The read-only rule is also **not a philosophical preference here**: it is what makes the agent-facing plugin need configuration before it is safe (P0-c), and what kills Graft outright.
- **`graphify hook install`** — same class of violation, and `AGENTS.md` forbids hooks inside a target explicitly.
- **`graphify update` against the target** — rewrites `<target>/graphify-out/graph.json` in place, no `--graph`/`--out` (`kg/graphify.py:1252-1276`); the plan's line at `docs/PLAN.md:212` must be corrected to `extract … --out`.
- **`graphify add <url>`** — duplicates `src/resextract/web/`, which already owns the web path.
