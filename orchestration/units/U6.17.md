# U6.17 — `tests/test_dashboard_auth.py` never touches the real store

**Status:** done · **Bound:** ≤20 tool calls (used 20) · **Zero LLM calls** · **Occamy probe `192.168.2.168:8012` -> `000` (DOWN, exit 7), probed once, nothing restarted.**

## Purpose (one sentence)

Make `tests/test_dashboard_auth.py` never read the real `state/state.sqlite`, and
thereby stop the `-wal`/`-shm` sidecar leak it causes at its source.

`tests/test_dashboard_auth.py`, `state/logs/U6.17*`, `orchestration/units/U6.17.md`,
`orchestration/handoffs/U6.17.json`.

**Why it was not isolated** — `tests/test_dashboard_auth.py:123`

```python
return app_mod.create_app(host="0.0.0.0", allow_remote=True, token=token)
```

no `store_path` -> `app.py:110 layer = api.DataLayer(store_path, journal_dir, …)`
with `None` -> `api.py:409 self.store_path, self.store_source =
resolve_store(store_path)` -> `api.py:371 return Path(DEFAULT_DB_PATH),
STORE_SOURCE_DEFAULT` = the **real** store. Every other construction in the file
(including the two in-process `main([…])` calls, via `__main__.py:112`) does the
same. The read-only open (`_connect`: `sqlite3.connect(f"file:{quoted}?mode=ro",
uri=True)`) is what emits the sidecars.

## Fix

One module-scoped **autouse** fixture, `isolated_store`, in the test file:

* `shutil.copyfile` of the real store into `tmp_path_factory` — a plain byte copy,
  the original is **never** opened, so the fixture cannot itself emit sidecars;
* sets `RESEXTRACT_STATE_DB` to the copy (rule two of `resolve_store`'s
  precedence, U6.16) — redirects **all** constructions in the file, including the
  spawned subprocess, with no call site to forget;
* restores the previous value (`pop` if unset) in a `finally`.

No assertion weakened or deleted. `pytest.raises(ValueError)`, `rc == 2`, the
`uvicorn.run` sentinel, `401` + `"token" in error`, and `set(body) == {"error"}`
are all intact.

**Isolation guard (new, fails if it regresses):**
`app.state.dashboard["store_path"] == str(isolated_store)`, `store_source == "env"`,
`store_resolution` matches, `!= str(api.DEFAULT_DB_PATH)`.
