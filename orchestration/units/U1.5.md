# U1.5 — Staging corpus + gated semantic ingest

**Purpose.** Make the repo's non-code research material reachable by the knowledge
graph. U1.4 proved graphify ingests 453/533 of `Duval` (84.99%) and named the
biggest invisible block: `.jsonl` (38, the measured `evals/`/`traces/` results)
then `.xml` (29). A normaliser existed; nothing fed its markdown to the graph.
This unit builds the feeder (a provenance-manifested staging corpus) and the
orchestrator that runs graphify's LLM pass over it, gated honestly on the endpoint.

**Hard bound.** ≤40 tool calls. Zero LLM calls unless the pre-flight probe returns
200 — and then exactly one bounded run. Tests: only `tests/test_kg_staging.py`.

**Write paths.** `src/resextract/kg/staging.py`; additive exports in
`src/resextract/kg/__init__.py`; `tests/test_kg_staging.py`;
`tests/fixtures/staging-repo/**`; `state/staging/**`; `state/kg/semantic/**`;
`state/kg/combined/**`; `state/logs/U1.5*`; `orchestration/units/U1.5.md`;
`orchestration/handoffs/U1.5.json`. `state/kg/duval/**` read-only.

## Deliverables

1. `staging.py`
   - `StagedFile(staged_path, original_path, kind, bytes_in, bytes_out, sampled, note)`,
     `kind ∈ {doc_copy, normalized, skipped}`.
   - `build_staging_corpus(...)` — copies the doc family (graphify's real
     `DOC_EXTENSIONS`) byte-for-byte to `docs/<rel>`; normalises `.jsonl`/`.csv`/`.tsv`/
     `.ipynb` through `ingest.normalize` and `.xml` through the new bounded stdlib
     `normalize_xml`; records every skip with a reason; caps files/bytes/normalisations.
   - `MANIFEST.json` — per staged file: `staged_path, original_path, kind, sha256,
     bytes_in, bytes_out, sampled, note`, plus counts/caps/skipped_by_reason/notes.
   - `resolve_provenance(staged_path, corpus_or_manifest)` — the inverse mapping
     (exact, absolute, path-shaped suffix, unambiguous basename).
   - `staging_summary(corpus)` — deterministic kind/extension counts, caps hit,
     still-uncovered types.
2. Semantic half — `SemanticResult`, `semantic_argv`, `semantic_ingest`,
   `merge_with_code_graph`, `combined_graph_report`. Pre-flight is one HTTP call;
   on failure it returns `blocked_endpoint_down` with the exact argv and runs
   **nothing**. `merge-graphs` needs no LLM and is proven on real artifacts.
3. `tests/test_kg_staging.py` — 13 offline tests over `tests/fixtures/staging-repo/**`.
4. Red→green harness `state/logs/U1.5_redgreen/test_redgreen.py` — two seam reverts,
   both failing (`2 failed`); verbatim output pasted into the test module docstring.

## Hardened XML

Stdlib `xml.etree` only. DOCTYPE/ENTITY declarations are removed by a
bracket-aware byte scanner (not a backtracking regex); non-standard entity
references are neutralised to literal `&name;` text; external entities/DTDs are
never resolved; malformed XML yields a `kind="xml"` report with a raw prefix and
a note, never a crash.
