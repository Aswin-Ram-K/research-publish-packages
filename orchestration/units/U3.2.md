# U3.2 — Fetch + content-hash cache + change detection

**Status:** done (bridge live; 5 real fetches used of a 6 budget)
**Write paths:** `src/resextract/web/fetch.py`, `tests/test_web_fetch.py`,
`state/webcache/**`, `state/logs/U3.2*`, `orchestration/units/U3.2.md`,
`orchestration/handoffs/U3.2.json`

## Purpose

Given a URL, get its text + metadata reliably; given a URL already fetched, say
*exactly* whether it changed since. This is the "is my evidence still true?"
layer of the refresh engine.

## Contract implemented in `src/resextract/web/fetch.py`

* `FetchMeta(url, title, text, sha256, fetched_at, kind, page_date, http_status,
  bytes_in, cache_path)` and
  `FetchResult(ok, meta, error, from_cache, changed, detail, note)`
  (`detail` carries `old_sha256`/`new_sha256`; `note` carries
  `unchanged`/`content_changed`/`no_previous_copy`/`refresh_failed`).
* `Fetcher(bridge_url="http://127.0.0.1:8891", *, cache_dir="state/webcache",
  timeout_s=45.0, max_length=12000, scrape_fallback=True, min_interval_s=1.0,
  allow_private=False, clock=time.monotonic, sleep=time.sleep, transport=None)` —
  injected clock/sleep make pacing testable; an injected `httpx` transport makes
  the whole class offline-testable.
* `fetch(url, *, force=False, max_length=None, mode=None)` — SSRF guard first,
  then cache (key `sha256(url)`, `state/webcache/<key>.json` + `<key>.txt`; a hit
  performs **zero** HTTP calls, `from_cache=True`), then `POST /crawl`, then
  `POST /scrape` fallback (`mode`, default `smart`) recorded in `kind`.
* `refresh(url)` — refetches and compares content digests: differing ⇒
  `changed=True, note="content_changed"`; identical ⇒ `changed=False,
  note="unchanged"`; no cached copy ⇒ `changed=True, note="no_previous_copy"`.
* `check(url, *, use_cache=False, max_length=600)` — cheap `(ok, error)`
  reachability probe cached under a separate `-check` key so it never overwrites
  the full-text copy.
* sha256 is over the **NFC-normalised UTF-8** text; `bytes_in` is the byte size of
  the full untruncated text while `text` is truncated to `max_length`.
* `page_date` (ISO or `None`): arXiv `Submitted on 29 May 2025` / `last revised
  12 Mar 2026`, `<time datetime=...>`, ISO `YYYY-MM-DD` in the first 3000 chars.
  Invalid dates (`2025-13-45`, `31 Feb 2025`) and dates past the head window are
  `None` — never invented.
* Failures are values, never exceptions: `blocked_url`, `pdf_not_supported`,
  `empty_response`, `timeout`, `transport_error: …`, `bridge_http_error`.
  PDF URLs (by `.pdf` path or `%PDF-`/`application/pdf` bytes) are recorded as a
  `kind="pdf"` cache entry and reported `pdf_not_supported` — the Docling bridge
  is never a dependency.
* SSRF guard (before cache *and* before any socket): non-http(s) schemes; loopback
  (`127/8`, `::1`, `localhost`), link-local (`169.254/16`, `fe80::/10`), private
  (`10/8`, `172.16/12`, `192.168/16`, `100.64/10`, ULA), metadata
  (`169.254.169.254`, `fd00:ec2::254`) — hostnames are resolved first via the
  module-level `_resolve_host` (monkeypatchable, so the suite stays offline) and a
  DNS name pointing at loopback is refused; `allow_private=True` lifts only the
  address checks, never the scheme check.

## Notes / hazards

* The guard also runs on a cache hit, so a cached-but-now-private URL is refused.
* Cache JSON carries the stored (truncated) `text` field plus a separate `.txt`;
  the `.txt` is authoritative on read.
* `state/webcache` now holds entries for the 5 live URLs (evidence, reusable).
* Importing this module executes `resextract/web/__init__.py`, which U3.1 owns and
  which imports `.search`; if that file is mid-edit, `web.fetch` cannot import.
  Nothing in `fetch.py` imports `.search`.
* Offline suite is the gate; live runs are evidence only, and the bridge being
  down yields `partial` (not the case here).
