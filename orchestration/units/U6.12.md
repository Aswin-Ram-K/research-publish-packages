# U6.12 — remote reads are no longer anonymous

**Purpose.** U6.9 proved live that `--allow-remote` served the dashboard's READ
routes (store, journals, dockets, graph) to the network with no token; only
`POST /api/control/*` was gated.

**Rule (one sentence).** A non-loopback bind requires an operator-chosen token,
and that same token is then required for every route — reads included; loopback
keeps anonymous reads and `--token auto`.

**Choice.** (c) both: reads are token-gated on a non-loopback bind *and* the bind
is refused unless an explicit (non-`auto`) token was supplied.
