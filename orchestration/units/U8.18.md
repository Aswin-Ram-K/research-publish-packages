## Discriminator and its failure mode
Verifier iff basename starts with `V` **or** the doc carries `verdict`/`overall`; else unit.
Misclassification is **fail-loud**, not fail-silent: a unit report carrying `overall` is judged as a
verdict and fails on missing `checks`; a `V*` file that is really a unit report fails on missing
`overall`. `V5.26.json` fails under *either* discriminator, so the current red is not caused by the
discriminator choice.
