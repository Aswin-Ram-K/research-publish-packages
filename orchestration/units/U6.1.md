# U6.1 — Dashboard (local, loopback-only read surface)

**Status:** done · **Batch:** 6 · **Author:** U6.1 · **Max bound:** 40 tool calls

## Purpose
The headline requirement: a standalone local app with a web dashboard showing all
the reasoning and findings behind the extracted research material, while the
material stays a folder on disk. This unit builds the read surface over the
**real** store, journal and docket tree — no LLM calls, no network fetches.

## Data layer (`api.py`)
`DataLayer` (plus module-level wrappers for the spec names) over store / journal
/ dockets / graph / doctor. Every method returns JSON-serialisable dicts and
never raises: a missing store, absent table or unreadable docket yields
`{"error": "..."}`. Reads are capped (`max_bytes`, default 2 MiB); the graph is
hashed by streaming and summarised with `graph_stats`.

Honesty highlights:
- `reasoning_trace()` reports `fields_present`, `reasoning_text_available` and
  `reasoning_tokens_recorded`. Today's journals record `reasoning_tokens` but
  **not** `reasoning_content`; the payload says so and the note names the gap.
- `findings()` merges store rejections with miner `candidate_rejected` journal
  events and returns `rejected_reasons`, so the honesty mechanism is visible.
- `web_research_health()` classifies sources `current/changed/gone/suspect` and
  reports `degraded` from real `search_health` failures; with zero rows it says
  the degradation is not observable from the store yet.
- `dockets()` calls `verify_docket` per docket and marks a corrupt manifest
  `status: "unreadable"` with the parser error.
- `doctor_status()` calls the real probe layer; Occamy is **down** and shown down.

## Server (`app.py`)
`create_app(store_path, journal_dir, dockets_dir, *, graph_path, token, host,
allow_remote, max_bytes)`. Routes: `/`, `/static/*`, `/api/{status,runs,
reasoning,findings,dockets,dockets/{slug:path},web-health,graph,doctor,refresh}`,
`GET /api/events` (SSE, `sse-starlette`, heartbeat every 1 s + journal/docket/
doctor change events), and token-gated `POST /api/control/{rescan,doctor}`.

Safety: `check_bind_host()` refuses non-loopback hosts unless `allow_remote`;
`safe_slug()` rejects `/`, `..`, NUL, leading dot (route answers 404); control
routes require `X-Dashboard-Token` (or a bearer token) when a token is set, read
routes stay open; a hard byte cap bounds every read.
