# U3.3 — finalize the `web` package: one public surface, two honesty gaps closed

**Status:** done · **Parent:** session-b7412b4f-5aaf-4115-8a4b-262c23914dd2
**Predecessors:** U3.1 (`web/search.py`, 12 tests), U3.2 (`web/fetch.py`, 52 tests)

## Purpose

Give `resextract.web` one deliberate public surface and close the two honesty gaps
that the predecessor units' live runs exposed:

1. **A dead SearXNG answers in milliseconds.** Live: genuine answers 172–948 ms;
   zero-result responses 2.0–2.6 ms, with `unresponsive_engines: []` — the service
   does not self-report. Waiting for three consecutive empties (≈4.5 s of pacing)
   is too slow when one sub-50 ms empty is already diagnostic.
2. **A crawl can return a stub and still report `ok=True`.** Live: a `gpt-2`
   README "fetch" returned 25 chars (` ```\n404: Not Found\n``` `) and was recorded
   `ok=True`; only empty/whitespace triggered the scrape fallback, so a short
   payload would have been cited as evidence.

## Hard bound (as executed)

≤35 tool calls (used ~27) · ≤6 real SearXNG queries (used 5, incl. 1 liveness
search) · ≤6 real fetches (used 3 = 5 bridge HTTP calls) · `/tmp` never used;
backups under `state/logs/`.

## Changes

- `search.py`: constructor knobs `fast_empty_ms=50.0`, `fast_empty_escalates=True`;
  a zero-result outcome whose producing `ok=True` attempt took `< fast_empty_ms`
  latches `degraded` immediately with `degradation_reason="fast_empty"`; the
  3-consecutive rule is the second path with `reason="consecutive_empty"`;
  `degradation_evidence` is now `DegradationEvidence(query, reason, latency_ms, ts)`;
  attempt latency is measured on the injected clock so the escalation is testable;
  `ok=False` (transport) stays its own path. `fast_empty_escalates=False` restores
  the old rule.
- `fetch.py`: constructor knobs `min_chars=200`, `suspect_is_error=False`;
  a crawl under `min_chars` triggers the scrape fallback (longer payload wins);
  a still-short final payload returns `ok=True, suspect=True,
  suspicion="short_payload", usable_chars=N` (or `ok=False, error="short_payload"`),
  is still cached, and stays suspect through `refresh()` and cache hits;
  `check()` now returns `(ok, error, suspect)`; `usable_chars` counts the received
  payload before `max_length` truncation.
- `__init__.py`: explicit `__all__` for both modules; the real hit class is
  `Result` (there is no `SearchResult` class to export); module docstring states
  the invariant — *an empty or stub response is never evidence of absence, and
  never evidence of content*.
- Tests: 12 → 17 (`test_web_search.py`) and 52 → 61 (`test_web_fetch.py`).
