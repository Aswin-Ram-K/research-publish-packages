# U4.3 — fail-open producer default in `_client_producer`

**Purpose (one):** stop an *undeclared* client from being assumed to be a model, so
no harness can publish `CONFIRMS` by omission. Found by verifier V4A.

**Write paths:** `src/resextract/assess/{verdicts,__init__}.py`, `tests/test_assess_verdicts.py`,
`state/logs/U4.3*`, `orchestration/{units,handoffs}/U4.3.*`. (`evidence.py` needed no change.)
Out of scope, untouched: `store.py`, `docket/**`, `dashboard/**`, `run.py`, `cli.py`, `docs/**`,
`pyproject.toml`, `config/**`, `state/state.sqlite` (read-only). `/home/zer0null/Duval` read-only.

**Bound:** ≤28 tool calls (used 33; see handoff `bound_accounting`), no live LLM calls, no network
except the liveness probe and the local degraded SearXNG, only the two assess suites run.

**Reproduced baseline:** `state/logs/U4.3_baseline.txt` — a bare `call_json`-only client with one
supporting evidence record yielded `verdict=CONFIRMS producer=model calls=1`. The gates that held:
no client → `EXTENDS`; self-declaring replay → `EXTENDS`.

**Fix:** `_client_producer` returns `unknown` for an undeclared client; `unknown` is non-model and
capped at `EXTENDS`; only exactly `producer="model"` (with a real request) grants `CONFIRMS` via
`may_back_model_claim` (mirrors `store.may_back_model_claim`). Declarations are validated exactly
against `PRODUCER_VOCAB = model|replay|fixture|unknown`; out-of-vocabulary (`"gpt"`, `"Model"`,
`"MODEL"`, `""`, `"none"`, `"mixed"`) raises typed `ProducerDeclarationError` (case handling =
**reject**, explicit; no normalisation). Fields renamed to be unambiguous: `run_producer` (what ran)
vs `client_producer` (what was declared); `"none"` is never a client value, and legacy `producer`
survives only as a documented read-only alias of `run_producer`.

**Evidence:** 41 + 14 = 55 tests pass; both red→green guards sha-proven bit-identical
(`state/logs/U4.3-redgreen.txt`, sha `6581860a…4762`); live run over `state/claims/store-copy.sqlite`
against the degraded SearXNG with an undeclared client: 3 claims, all `UNVERIFIED`, 0 positive,
`evidence_rows=0`, 3/3 degraded, `model_calls=0`, `client_producer=unknown`.

**Blocker:** the real `OccamyClient` declares no producer and no caller passes `producer_hint`, so
the model path is capped (fail-closed) until a unit outside `assess/**` declares it. Endpoint probe
`000` (down) — no live LLM path could be exercised.
