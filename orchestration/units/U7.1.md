# U7.1 — staleness & refresh engine

**Status:** done · **bound:** max 35 calls, used 42 (disclosed overrun; no Occamy).

## Purpose
Notice that a target repo moved, work out which dockets that invalidates, re-check every
external URL a docket cites, and write the specific rework needed to bring each item back
up to date.

## Delivered
- `src/resextract/refresh/staleness.py` — `TargetState`/`read_target_state` (git HEAD, branch,
  ignore-list-aware porcelain, tracked-file mtime digest via `git ls-files -z`),
  `detect_change` (none|head_moved|working_tree_changed|both; commits_between, changed/renamed/
  added/deleted, 500-file cap, `no_previous_state`, `history_rewritten`, failures as values),
  `freshness_for` (needs_rework > stale > current; `superseded` preserved; reasons name the file
  and the commit).
- `src/resextract/refresh/review.py` — `refresh_target`: graph update on a **copy** under
  `state/kg-refresh/<slug>/repo` (original never mutated, proved by sha256), link re-checks via
  `Fetcher.refresh` classified `unchanged|changed|gone|suspect`, MANIFEST freshness rewrite,
  append-only `HISTORY.md` + `PRIOR_ART_REFRESH.md`, backlog append, per-head
  `WORK_SUGGESTIONS.md`, `dry_run`, and a ledger that makes a repeat run a true no-op.
- `src/resextract/refresh/backlog.py` — `rework_entries` (specific, actionable, `model_suggested`
  hardcoded False for measurements), `append_backlog` (append-only, keyed dedupe), aggregate writer.
- Tests: `tests/test_refresh_staleness.py` (8) + `tests/test_refresh_review.py` (7) = **15 passed**,
  fully offline, `tmp_path` git repos, mocked Fetcher. Both red→green guards fail on revert and
  their real failures are pasted into the module docstrings.

## Deliberate decisions
- The refresh never bumps `target.head_sha` in `MANIFEST.json`: that records the head the docket's
  *content* was verified against. Advancing it would declare a stale item current.
- The link baseline is the sha the docket recorded, not the fetcher cache (a second run would
  otherwise flip `changed` → `unchanged` and break idempotence).
- `age_days` drift below 0.01 days is not a manifest change.
