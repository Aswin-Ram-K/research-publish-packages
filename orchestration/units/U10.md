# U10 — characterise the 64-boundary first-repeat miss

**Status:** done · **Verdict:** `boundary_specific` · 159 live requests (of 160) · 0 wire failures

## Purpose

Two independent units hit the same unexplained wall. U9 saw, at exactly
`prompt_tokens == 1024`, that an immediately repeated identical request reported
`cached = 0` and paid full prefill (207 ms) while the second repeat hit 960
(86 ms) — 3/3 at 1024, 0/4 at 1021–1023. U4b lost one of eight fan-out branches
to a `cached = 0` on its first warm request. This unit had to turn that into a
stated, bounded finding: is the miss specific to `L % 64 == 0`, is it a general
first-repeat race, or does it not reproduce at n=5?

## Hard bound (declared before the first live request)

≤ 160 live requests, ≤ 20 minutes, one request in flight, **no file lock** (other
units hold it and token counts do not need it), **never** `POST /flush_cache`.
Stop and write `blocked` after three consecutive request failures.

## Write paths (only these)

`experiments/context-cache/cells/U10/**`, `orchestration/handoffs/U10.json`,
`orchestration/units/U10.md`.

## Design

* **Length is the only variable.** Cells: 1024, 1023, 1025, 1088, 1008 tokens;
  five trials per cell, fresh marker per trial.
* **Exact lengths are achievable only with a token-stable cold marker.** U9's
  16-hex salt jitters ±2 tokens (its own logs: declared 1024 → achieved
  {1021…1025} across 43 requests), which is fatal on a 64-token boundary. Here
  `make_salt(seed)` still generates the salt, but its digits select three
  fixed-width four-letter marker words (always 20 characters, always the same
  token cost), and the body is sized twelve tokens short with a one-token tail
  (`" the"` repeated) to close the gap. Every response's `prompt_tokens` is read
  back; a cold request whose achieved length is wrong is logged as a *probe*,
  the knobs are corrected, and the trial is retried. Every cell landed exactly.
* **Cold is verified, never assumed.** A cold role that reports `cached != 0` is
  retried with a fresh marker and noted. No retries were needed.
* **Miss definitions.** `full_miss` = `cached == 0`; `partial` =
  `0 < cached < 64*floor((L-1)/64)`; `hit` = `cached == 64*floor((L-1)/64)`.
* **Phases.** p1 length sweep; p2 delay (0.25/0.5/1.0/2.0 s, d=0 from p1) at the
  worst cell; p3 one 63-token unrelated request inserted between cold and repeat.

## Result

| L | L%64 | rep1 full misses | rep1 cached | rep2 misses | rep2 cached |
|---|---|---|---|---|---|
| 1008 | 48 | 0/5 | 960 ×5 | — | — |
| 1023 | 63 | 0/5 | 960 ×5 | — | — |
| 1024 | 0 | **5/5** | 0 ×5 | 0/5 | 960 ×5 |
| 1025 | 1 | 0/5 | 1024 ×5 | — | — |
| 1088 | 0 | **5/5** | 0 ×5 | 0/5 | 1024 ×5 |

* Pooled: multiples of 64 **10/10** (Clopper-Pearson 95% CI 0.6915–1.0);
  non-multiples **0/15** (CI 0.0–0.218); Fisher two-sided **p = 3.06e-07**.
* **Delay does not fix it:** 0.25/0.5/1.0/2.0 s → 5/5 full misses each (20/20),
  repeat TTFT medians 770/443/553/521 ms (full prefill).
* **An intervening request does not fix it:** 5/5 full misses.
* **A second identical repeat does:** rep2 10/10 hits, exactly at
  `64*((L-1)//64)`.
* Cost of the miss: at L=1024 the immediate repeat's TTFT median 268.4 ms against
  80.4–111.7 ms for a hit at the neighbouring lengths.

**Mechanism.** Not insert latency and not a request-triggered flush: a 2 s wait
and an unrelated request in between both leave the miss at 100%, while the third
send of the same bytes hits. The prefix becomes reusable only after it has been
prefilled twice — so a multiple-of-64 workload loses one full prefill per new
prefix.

**Which earlier observation this explains.** U9's 1024 case: yes, exactly (same
length, same shape, same numbers, now 5/5). U4b's branch-2 case: **no** — its
fan-out prompts were ~1925 tokens (1925 % 64 = 5), a residue class with 0/15
misses here, and its lost branch was prefix-sharing with a different suffix
rather than an identical repeat.

## Limitations

* n=5 per cell, so a single cell's CI is wide (0/5 → [0, 0.52]); the claim rests
  on the pooled contrast, not one cell.
* 960, 1020, 1028, 1152, 2048 and 4096 from the card's list were not run: 39 of
  the 160 requests went on pilot probes needed to build an exact-length harness
  (`u10_pilot.json`), and the remaining 121 also had to pay for phases 2 and 3.
* Only identical repeats are measured at n=5. The prefix-sharing shape that U4b
  hit is covered by one pilot probe (also `cached = 0`), not by a cell.
