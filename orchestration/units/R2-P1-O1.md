# R2-P1-O1 — Round-2 prompt factorial, cell 1 of 4 (setup O1, production SGLang)

**Purpose.** Measure five prompt/policy arms against the SAME task content on the
production occamy-1.0 MoE endpoint, so Round 2 has a like-for-like comparator
(A vs C0, and A vs R) on a 131k-context MoE with `--page-size 1`.

**Substrate — untouched.** `http://192.168.2.168:8012/v1`, container
`gx10-occamy-nvfp4`, `max_model_len 131072`, grid unit 64. No restart, no
reconfigure: production is the substrate. `/v1/models` returned 200 at the end.

**Arms** (verbatim from `cells/PROMPT-O2-EXTRA/prompt_o2e_cell.py` and
`cells/PROMPT-O4/prompt_o4_cell.py`; renderer imported from `cells/VLLM-CELL/vllm_cell.py`):
R (re-send all) · A (pointer index + newest delta) · C (A, tag at delta end) ·
H (mid-context compaction) · C0 (plain-chat transcript).

**Bound.** 5 × 71 turns = 355 rows at budget 32768. Request cap 400; used 103.

**Result.** gcd 64; R 390.80 unc/turn (hit 0.9670), C0 713.77 (0.9431),
A 529.48 (0.7701), C 547.86 (0.7634), H 941.46 (0.6154).
A−R = +133.32, CI [123.7, 143.0], excludes 0. Headline A/R = 1.3549.

**Write paths.** `experiments/context-cache/cells/R2-P1-O1/**`,
`state/logs/R2-P1-O1-progress.log`, `orchestration/handoffs/R2-P1-O1.json`, this file.

**Incident.** A host restart killed the run mid-H (254 rows). Resumed from the last
complete row; the warm-up was re-run on resume (it is the instrument gate, not a
measurement) and the rows before it were preserved. Final `rows.jsonl` is the
single append-only artefact: 355 rows.
