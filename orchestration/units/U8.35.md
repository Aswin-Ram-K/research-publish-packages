## Defect (V8.29, PASS, quoted)
"a torn write can be byte-identical across the double read ⇒ HARD failure, so the docstring's
'does not flicker' holds only for short tears … '10 passed / 0 failed' is not reproducible on a
busy corpus (9 passed / 1 failed full file)". Recurred live at `V8.27.json` 09:44 and
`U8.28.json` 09:47. Mechanism: the guard skipped a file only when its bytes differed between two
*immediate* reads; a mid-flush file can present the same partial bytes twice ⇒ looks settled ⇒
parsed ⇒ `JSONDecodeError` ⇒ hard failure.

## Purpose
1. Replace the immediate double-read with a **bounded settle loop** (200 ms × 4 attempts) that
   separates *settled defect* (still a hard failure) from *unfinished write* (a skip with a reason).
2. Add the **REMEDY** line to `test_no_baseline_entry_over_declares`' assertion message.
3. Two tightenings: retire the unused `_regressions` `shapes` parameter; tighten the
   `"… or \"delimiter\""` assertion to a conjunction that is not version-fragile.
