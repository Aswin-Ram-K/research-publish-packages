## What changed (all additive: ADD COLUMN / CREATE TABLE IF NOT EXISTS / CREATE UNIQUE INDEX)
1. `rework` + `source_ref TEXT`, + `model_suggested INTEGER NOT NULL DEFAULT 0 CHECK(0,1)`;
   `add_rework()` dedupes on `(docket_id, reason, source_ref)` and returns `(id, inserted)`;
   `list_rework(docket_id=None, open_only=False)`; `open_rework` kept int-returning.
2. `lane_candidates(lane_id, candidate_id)` PK + index on `candidate_id` (and `lane_id`),
   FK `ON DELETE CASCADE`; accessors `link_lane_candidates`, `lane_candidate_ids`,
   `candidates_for_lane`, `lanes_for_candidate`, `unlinked_candidates`.
3. `dockets_dir_unique ON dockets(dir)`; `upsert_docket_by_dir()` returns `(id, inserted)`
   and merges partial updates with COALESCE. `upsert_docket(id=...)` unchanged (returns int,
   `docket/materialize.py` depends on that); `id=None, dir=...` is now by-dir.
   Pre-existing duplicates are reported (`find_duplicate_dockets`) then resolved
   deterministically before the index (`resolve_docket_dir_duplicates`): keeper = newest
   `verified_at`, rework rows re-pointed, losers merged.
