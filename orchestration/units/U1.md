## Key design decisions

- `StateNode` stores a private `_parent` back-pointer (excluded from equality/
  repr) so `chain()` needs no global registry; identity stays the content hash.
- `POINTER` renders preamble+pointer-table as the invariant head and only the
  newest delta message; the pointer table lists non-delta nodes, so appending a
  turn never rewrites an earlier message.
- `compact(FORK)` re-creates every node under a new `fork` root; new ids are
  disjoint from old ids and no new `parent_id` points into the old chain.
- `CacheRow.prefix_sha256` is the digest of the *invariant head* (2 messages for
  pointer policies, 1 otherwise), not the whole render, so appending a turn is
  not misread as a cache break.
- Eviction: cold-start check applies to rep 1 only (later reps are supposed to
  hit); the first turn after compaction is exempt.

## Deviation from the unit card (all additive, none changing contracted names)

1. `compact(...)` accepts an optional `est_tokens=` kwarg (default
   `default_est_tokens`) so the `CompactionEvent` token counts are computable
   without changing the required call shape.
2. `render_bytes` is joined by `first_message_bytes` (the exact prefix helper);
   `nodes.canonical_bytes`/`digest`, `salt.salted`, `meter.rows_from_jsonl` are
   helpers exported from the package.
3. The cell-matrix corpus definitions (`Cell`, `Case`, `Turn`, `build_cells`)
   live in `runner.py`; this is the "matrix" the card asks the runner to execute.
4. `pyproject.toml` still lists `packages = ["resextract"]` and was NOT edited
   (outside write paths); `resextract.context` imports through the editable
   src path, verified by the passing suite. A packaging unit may want to add
   the subpackage if wheels are built.
