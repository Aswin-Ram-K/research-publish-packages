### The corrected rule, as the code implements it (read, not paraphrased)

`_same_digest` (run.py:943–947):

```python
if not reported or not pinned:
    return False
a, b = reported.strip().lower(), pinned.strip().lower()
width = min(len(a), len(b), 64)
return width >= 12 and a[:width] == b[:width]
```

* **< 12 hex → refused as a mismatch.** `width >= 12` is a floor, not a tolerance; the pin cannot be compared at all, so the mismatch branch (run.py:1170) refuses it — fail-closed. No `PIN ABBREVIATED` note, because that note is emitted only on the match branch (run.py:1161).
* **12–63 hex that matches → accepted, reported loudly** (`PIN ABBREVIATED` note run.py:1161–1169 + `REDUCED STRENGTH` clause run.py:1009–1013).
* **64 hex that matches → accepted silently.**
* **> 64 hex → refused** (`PIN OVERLONG` note + `_note_unusable` refusal, run.py:1112–1136; checked *before* the comparison, via `_pin_is_overlong`, run.py:928).

**The card's three-part rule matches the code exactly**; no discrepancy. The only nuance added is the absent `PIN ABBREVIATED` note for <12.
