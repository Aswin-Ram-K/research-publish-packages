# U6.3 — dashboard suite must not depend on a pre-generated fixture

**Status:** done · **Bound:** ≤25 tool calls (used 22) · **LLM calls:** 0 · **Network:** none

## Purpose
Fix the reproducibility defect reported against `tests/test_dashboard.py`: the
suite was said to depend on a generated `tests/fixtures/dashboard-store/state.sqlite`
that is not on disk, so a fresh checkout shows a red dashboard suite.

## Diagnosis (differs from the report — reported accurately)
- `state.sqlite`, `state.sqlite-shm`, `state.sqlite-wal` **are committed at HEAD**
  (`git ls-tree -r HEAD`), and `git check-ignore` says **NOT-IGNORED**. The file
  *was present on disk*. So "generated fixture missing from disk" is a stale
  observation, and committing SQLite `-shm`/`-wal` sidecars is itself a smell.
- The real, reproducible fresh-checkout hole: `.gitignore` line 3 is the
  unanchored rule `dockets/`, which matches
  `tests/fixtures/dashboard-store/dockets/` at **any depth**. The valid and
  corrupt docket trees are therefore untracked and absent on a fresh clone.
- Emulating a fresh checkout (gitignored `dockets/` removed, tracked DB kept):
  **5 failed, 43 passed**. Also removing the committed DB: **12 failed, 36 passed**.

## Fix
- `tests/fixtures/dashboard-store/build.py`: new `build(dest_dir) -> Path`
  callable (thin `_write_tree(ROOT=...)` shim over the existing `main()` body,
  so the fixture data is byte-for-byte unchanged). Writes only under `dest_dir`.
- `tests/test_dashboard.py`: session-scoped **autouse** `_dashboard_fixture`
  imports `build.py` by path and builds the whole tree into
  `tmp_path_factory.mktemp("dashboard-store")`, then rebinds
  `STORE/JOURNALS/DOCKETS/EMPTY_DOCKETS/GRAPH` to it. `FIXTURES` is untouched
  and still supplies only deliberately-missing paths (`nope.json`,
  `does-not-exist.sqlite`, `no-dockets-here`).
- Strategy chosen: **always build into `tmp_path`** (strictly stronger than
  "build when absent"): the suite is hermetic, leaves no artefact, and is immune
  to the concurrent v2→v3 store migration and to the gitignored `dockets/` gap.
