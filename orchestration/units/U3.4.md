## One purpose
Make "no prior art exists" impossible to conclude from a search that was actually broken, and add the
regression guards an independent verifier (V3) proved were missing.

## Findings acted on (measured by V3, not re-derived)
1. **A claim was refuted live.** `unresponsive_engines` is *not* empty when SearXNG returns nothing: 3 paced
   queries returned zero results while the raw envelope carried `[brave Suspended, duckduckgo CAPTCHA,
   qwant CAPTCHA]`. The client parsed that field and discarded it.
2. **Latency is a lower bound, not a classifier.** A slow zero-result response (340 ms observed; **494 ms
   re-observed live in this unit**) can be a dead search.
3. **Four invariants held in code with no test guarding them** (transport-failure not negatively cached;
   4xx/5xx ⇒ `ok=False`; empty/malformed body ⇒ `ok=False`; the `degraded` latch survives a later success).

## What changed — `src/resextract/web/search.py`
- `Attempt` gains `unresponsive_engines: list[str]` and `responded_engines: list[str]`; both are on the
  `Attempt` object passed to the existing `sink`, so a later unit can persist them into `search_health`
  (the store was not touched).
- `SearchOutcome` gains `absence_is_meaningful: bool`, `absence_reason: str | None`,
  `unresponsive_engines`, `responded_engines`. `absence_is_meaningful` is `True` **only** for an empty
  outcome that is `ok`, quiet (no unresponsive engine), latency `>= fast_empty_ms`, **and** produced while
  the latch was clear (documented deliberate strengthening; pinned by truth-table row F). Otherwise it is
  `False` and `absence_reason` names the contributing conditions (unresponsive engines / sub-threshold
  latency / transport failure / negative-cache hit / already-degraded client).
- New third degradation reason **`engine_unresponsive`**, filed **immediately** like `fast_empty` — a
  directly-reported failure outranks a heuristic. `fast_empty` and `consecutive_empty` are untouched.
- `_normalise_unresponsive` accepts the bare-string, colon-string, `[engine, reason]` pair and dict shapes
  and emits `"engine: reason"` (order preserved, duplicates dropped). `DegradationEvidence` carries the
  reported engines.
- Module docstring now states the guarantee in one sentence: *an empty result set is never by itself
  evidence that nothing exists; only a successful, quiet, slow-enough empty search is.*

`src/resextract/web/__init__.py` was **left byte-identical** (sha256 in the handoff): nothing needed
exporting at package level, and no name was removed (`__all__` stays at 13).
