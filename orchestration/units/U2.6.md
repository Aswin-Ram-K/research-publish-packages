1. **Boundary (ITEM 1).** `assess_claims` checks the store version once, at run
   start: raises `SchemaTooOldError` (naming `init_db` / `migrate_copy`) or, with the
   new opt-in `migrate_store=True`, calls `store.migrate_copy` on a **run-scoped copy**
   (source backed up + sha256 recorded, never written) and reports it on
   `report.migration`. `SchemaTooOldError` is re-raised out of the per-claim isolation.
2. **Hint (ITEM 2).** Client declaration authoritative; `producer_hint` may never
   upgrade (ignored when it would), may only deny/downgrade; out-of-vocab still raises
   `ProducerDeclarationError`. `value._client_producer` now delegates to the verdicts
   one (same function object).
3. **One predicate (ITEM 3).** `PRODUCER_VOCAB`, `MODEL_PRODUCER` and the predicate
   now live **only** in `store`; `assess.verdicts.may_back_model_claim` **is**
   `store.producer_is_model` (identity asserted). 5 literal comparisons and 2 duplicate
   constant definitions removed. The store comment is now true.
4. **`verdicts.model` — wired.** The writer records `producer` always and `model` only
   for a model producer; `insert_verdict` refuses `model=` with a non-model producer.
5. **Repairs.** (a) test_store_v3: 4 assertion lines deleted / 7 pins added — all four
   were version literals, 0 substantive, nothing restored. (b) migration-4 note basis
