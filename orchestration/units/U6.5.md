## Fix
`safe_slug` is unchanged. New `safe_docket_slug(slug, dockets_dir)`:
1. rejects backslash/NUL anywhere; splits on `/`;
2. requires **every segment** to pass `safe_slug` unchanged (so `..`, `.`, empty segments, leading dots and `%`-junk all still refuse);
3. `realpath`s the joined path and requires containment inside `realpath(dockets_dir)` — a symlinked docket escaping the root is refused (input `escape`, `duval/up`).
`duval/../_smoke` is **refused, not normalised** (decision): normalising silently accepts a client-supplied traversal path, and `_smoke` is reachable directly. Missing/corrupt manifest → explicit error payload, never a 500.
