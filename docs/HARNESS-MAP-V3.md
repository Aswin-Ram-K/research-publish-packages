## 6. Did building an experiment get cheaper?

**Not measurable yet — and the missing instrument is now precise: there is no gated, completed cell.** The batch
added the gates (G1/G2/G3, exits 4/8/12), the one-command conductor, the ledger, the projection, the TVS metric and
the regrade command, and then ran **zero** live cells: no `cell-*.gates.json` newer than `HARNESS-MAP-V2.json`
exists, no `rows-*.jsonl` was written, and the only new `cell-*` files are grade-v5 outputs regenerated from older
rows. So the price of *one experiment* — the number the operator actually asked for — cannot be read from any
artefact. What can be read is the **process** cost, and it did not fall: 25 cards, 0 requests, median 237 s of
wall-clock per card, only 2 of 25 cards recording their tool calls, and 62 % of recorded commands re-checking
instead of changing; the one card that owned the last live bypass delivered nothing. The proxy that does exist is
`TVS`: **111,994 tokens per verified success**, over 23 declared run/arm pairs of which **22 were never produced** —
a cost per success that is an artefact of a tiny denominator, not a harness improvement. To answer the question,
one cell must run end-to-end through `cell.py` (preflight → G1/G2/G3 verdicts in `cell-<arm>-<stamp>.gates.json` →
rows → grade → analyse → record) and be compared, card-rounds and requests, against `v1`'s **40 rounds / 863
requests**. Until that record exists, every "cheaper" statement is a claim about documents, not about experiments.

**Instrument that must be built next:** a `cell.py run` that actually emits `cell-<arm>-<stamp>.json` **and**
`.gates.json` — then `HARNESS-MAP-V4` can price a cell in requests, rounds and seconds instead of in pages.
