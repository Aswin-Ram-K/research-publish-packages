## 3. Root cause: the tool is wrong, not the packaging

The release is defined by `repro/encoder-crossover-190-SANITISED/EXCLUDED.md` §3 E15: among the files
deliberately **not** shipped is `experiments/second-labeller-190/{…, reflex-decisions.sandbox.ts}`, because
"`cases.json` is regenerated by the included `parse_fixture.py`; `reflex-decisions.sandbox.ts` is a
**byte-identical duplicate** of the fixture … and is restored by one `cp` in the README." The *fixture*
ships (`fixture/reflex-decisions.ts`), and the SANITISED sandbox copy is absent from
`repro/encoder-crossover-190-SANITISED/second-labeller/` by design. So `parse_fixture.py` is the defect: it
names a path the packaging policy excludes instead of the instrument that ships beside it.

The "byte-identical duplicate" half of E15 is **false against disk** and must not be banked on:

| file | bytes | sha256 |
|---|---|---|
| `experiments/second-labeller-190/reflex-decisions.sandbox.ts` (unreleased original) | 145,031 | `076164ac53c2c1aac130953345c481f88b51f4d6fb93d465c7430308a99b4796` |
| `repro/encoder-crossover-190-SANITISED/fixture/reflex-decisions.ts` | 90,738 | `751dc007ba115dccc5815fdf97c9ce7b34b0dc990a6e57802d762e9b35ad9cae` |
| `scratch/udtag1/tree-five/fixture/reflex-decisions.ts` (shipped, NEUTRAL-TAG/v1) | 85,044 | `ba810aa15c736a38512a98e5ed938edb6e51c640b15ca7ecc562a59aaf182fc5` |

Of 190 question strings, **47 differ** between the unreleased original and the shipped neutralised fixture
(the identifiers were replaced by opaque tags). The original also carries `ERRATA` text and 21 `src/`

`src/**` module names §E1 protects. **It was not shipped, and UTOOL1 did not ship it.** Adding it to make a
tool run would have traded a broken tool for a leak of additional mechanism prose; the ship set was not
widened.

+SRC = os.path.join(HERE, os.pardir, "fixture", "reflex-decisions.ts")  # UTOOL1: shipped fixture; was "reflex-decisions.sandbox.ts" (not in the ship set)

other file in the tree differs** from `tree-five` (`only-diff=['second-labeller/parse_fixture.py']`).
Corrected file sha256 `a6d83a5b989372504d8702cdc32a83d5a9fff119382acf10723d8efca13cb2fa`.

**Why this is the same measurement, not a rescue-rename.** The input the earlier units measured was the
staged file of sha256 `ba810aa1…` (85,044 B) — the same bytes as `fixture/reflex-decisions.ts`, which is
also the file `second-labeller/RUN.json` and the FIX4 correction history describe as the parsed instrument.

outputs:
