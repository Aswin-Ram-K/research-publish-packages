## DELIVERED
- `OccamyClient` (async) + `SyncOccamyClient` façade (`client.sync()`).
- `chat(..., thinking=...)`: `thinking=False` sends
  `chat_template_kwargs.enable_thinking=false`; `thinking=True` sends no such
  key. `content` and `reasoning_content` are separate fields, never merged.
- Typed results: `content`, `reasoning_content`, `tool_calls`
  (name + parsed args dict + raw JSON string), `finish_reason`, `usage`
  (prompt/completion/reasoning/total), `wall_ms`, `model`, `request_id`,
  `attempts`, `raw_usage`.
- Tool-call merge defends against the upstream quirk (`"function": {"name":
  null}` continuation deltas): a null/empty name never becomes the name and
  never clobbers the announced one. Covered in both streamed and non-streamed
  shapes. Tool args that fail to parse keep `raw_arguments` and report
  `args_error` instead of lying.
- `run_tool_loop(messages, tools, handlers, *, max_steps=12, thinking=True)`:
  bounded, missing/failing handlers become error tool results (never crashes
  the loop), every step recorded as a JSON-serialisable `ToolLoopStep`.
- `call_json(messages, schema, *, thinking=False, max_tokens=512)`: pydantic
  validation, one retry with the schema + validation error echoed back, then
  `UnparseableOutput(raw_text, last_error)` — never a partial object.
- Retries: 5xx/timeout/connection → exponential backoff with jitter, max 4
  attempts; `400` (and other 4xx) → immediate `ModelRequestError(status,
  body)`; `429` → honours `Retry-After` (capped at 30 s).
- Metering: `usage_sink(UsageRecord)` on every call (success *and* failure),
  default no-op. `Budget(max_tokens, max_calls)` → `BudgetExhausted` checked
  before a request leaves the process.
- `api_key` defaults to `local`; never logged and never present in a trace or
  metering record (tested).
- Config read from `config/resextract.toml` via `tomllib` when readable, else
  the measured defaults.
