# U2.1 — Mine research-worthy candidates with verified provenance

**Status:** partial (code + tests + graph-side live evidence complete; the model stage is
externally blocked — see Blocker).

## Purpose
Build `resextract.mine`: mine research-worthy candidates from a real repository, each carrying
provenance **independently checked** against the knowledge graph and the target tree — never
provenance the model merely asserted.

## Deliverables (all under declared write paths)
- `src/resextract/mine/provenance.py` — `Provenance`, `ProvenanceVerdict`, `verify_provenance`.
  `graph_node` must exist in `by_id()`; `file_lines` (`path#L120` / `path#L120-L160`) must be
  realpath-contained in `target_root` with an in-range span; `doc_section` checks the file and,
  when given, the heading. Never raises; malformed ⇒ `exists=False, detail="malformed"`.
- `src/resextract/mine/candidates.py` — `Candidate`, `Rejected`, `Degradation`, `MineReport`,
  `Miner`. Battery selection spread across intents → `graphify query` → Occamy `call_json`
  (`thinking=True`, `max_tokens=4000`) → verify → reject-if-zero-verified / keep-good-refs and cap
  confidence → dedupe on `(kind, normalised_title)` → store + hash-chained journal + `CANDIDATES.md`
  / `candidates.jsonl` / `report.json`. Resume key `sha256(graph_hash + query + prompt_version + model)`
  under `<out_dir>/index/<graph_hash[:16]>.json`.
- `tests/test_mine_candidates.py` + `tests/fixtures/mine-mini/**` — 13 offline tests (MockTransport,
  synthetic graph, `StubGraphify` mimicking the CLI's label-as-id quirk, one real-CLI test on a copy
  of the fixture graph so no cache is left in the fixture tree).

## Findings that change the next unit
1. **Relative graph paths break `graphify query`.** With `Graphify(cwd=target_root)`, a relative
   `--graph state/kg/...` resolved against the target and every query exited 1. `Miner._load_graph`
   now `.resolve()`s the path. Keep passing absolute `--graph`.
2. **The CLI does not print node ids.** `graphify query` prints node *labels* as ids
   (`project()`, `types`), which never match `graph.by_id()` (`tools_derivation_projector_project`).
   The miner therefore resolves label+source_file(+location) → real id before building the prompt,
   and only offers refs it has already verified.
3. **Occamy at 192.168.2.168:8012 is down** (refused connections through ~10:50Z).
4. `/home/zer0null/Duval` HEAD moved during the unit (external `pull --ff-only`, 05:41:44 -0500);
   U2.1 ran only read-only git commands and wrote nothing inside the target.
