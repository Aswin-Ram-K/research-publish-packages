# U6.20 — docket metadata: artifact is the source of truth (read path only)

Supersedes U6.19 (died after its Step 0; partial handoff, no unit card, no logs, no edits).

**Defect.** `GET /api/dockets` published no `lane.title` and no evidence count: the entry's
`lane` field is the manifest's `lane.slug`, so the board reader saw `duval-replay-material`
where `Duval replay-sourced material` belongs, and `evidence` was absent entirely.
`dockets.manifest_json` (insert-time snapshot) still holds the pre-re-render damage
(`lane.title=None`, no `generated_by.producer`), which is what V5.20 measured.

**Fix (read path only; the store is never written).** The board now serves
`lane_title`, `title`, `evidence` and `source` from the on-disk `MANIFEST.json`; when the
manifest is absent or unreadable it falls back to the store snapshot (`source="store"`,
`store_status`, explicit `error`), with every store-row slug validated through
`safe_docket_slug` and required to be an existing directory under the dockets root.
Store-only dockets whose directory is gone are never resurrected. `docket_detail` gains
`source="manifest"`.

`verify.ok` failures measured at the release sha before any edit. Red→green proven with a
bit-identical `api.py` restore (sha `004d88fd...`). Live: real title + evidence 8 at
`/api/dockets`, server killed and proven gone. Store sha unchanged (`40e8aa0c...`, v4);
`immutable=1` never used. Full handoff: `orchestration/handoffs/U6.20.json`.
