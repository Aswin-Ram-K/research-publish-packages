## Honesty rules implemented

1. `absence_is_meaningful` is a hard gate. Empty **and** not meaningful ⇒ `degraded_searches` entry
   carrying the engine reason ⇒ `UNVERIFIED`. Empty **and** meaningful ⇒ `UNVERIFIED` with the
   *distinct* reason "a clean search found no matching prior art". The phrase "no prior art exists"
   appears nowhere in any output.
2. `suspect=True` fetches are counted in `suspect_fetches` and excluded from evidence.
3. No `CONFIRMS`/`EXTENDS`/`CONTRADICTS` without ≥1 cited evidence id; an LLM verdict citing none is
   rejected and falls back to `UNVERIFIED("no evidence cited")`.
4. `producer` (`model`|`replay`|`none`) recorded on every verdict. The store's `evidence`/`verdicts`
   tables have **no producer column** — reported as a gap, and the value is kept in
   `report.json`/`verdicts.jsonl` instead of being dropped.
5. A replay/stub client can never produce `CONFIRMS`: it is capped at `EXTENDS` with the cap noted in
   the rationale.
6. Weak sources (a fetched page containing none of the claim's key terms) are *recorded* with the
   mismatch named in `context`, never silently promoted.

## Gate order (fixed)

1. no evidence records ⇒ `UNVERIFIED` with the gather reason;
2. every search degraded and no usable evidence ⇒ `UNVERIFIED` naming the engine errors;
3. with a client ⇒ LLM verdict (`call_json`, `thinking=True`, `max_tokens=2048` — reasoning is counted
   inside `max_tokens` on this server) constrained to cite evidence ids;
4. without a client ⇒ deterministic, capped at `EXTENDS`.
