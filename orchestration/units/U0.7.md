# U0.7 — batch-scoped placeholder owners + regression guard

**Purpose.** Fix the bookkeeping defect V0 found: `src/resextract/cli.py`'s 11
subcommand placeholders named **live unit ids** as owners (`target` → `U1.1`,
which was the finished graphify integration gate; `run`/`mine` → `U2.1`;
`materialize`/`open`/`export` → `U5.2`, …). A reader could not tell what was
pending. Conform to the Batch-0 rule in `orchestration/STATUS.md`: **placeholder
owners are named by batch, never by a live unit id.**

**Write paths (only these).** `src/resextract/cli.py`, `tests/test_cli.py`,
`state/logs/U0.7*`, `orchestration/units/U0.7.md`,
`orchestration/handoffs/U0.7.json`.

**Hard bound.** ≤18 tool calls; run only `tests/test_cli.py` plus direct
invocations; no full suite, no network, no model calls, no graphify, no commits.
