# U5.18 — the single planned re-render of the two real Duval dockets

**Unit type:** data operation, one-shot. **Hard bound:** ≤26 tool calls, zero LLM calls,
no network, no graph build. **Status:** see `orchestration/handoffs/U5.18.json`.

## Purpose

Re-render `dockets/duval/duval-replay-material` and `dockets/duval/duval-u55-pinned`
**once**, supplying the two fields the on-disk manifests do not record (`lane.title`,
`evidence`), then prove that a subsequent **bare** re-assembly is information-preserving
(V5E found a pre-U5.14 manifest loses both: H1 collapses to the lane slug, EVIDENCE prose
is destroyed).

## Recipe (from V5E, `state/verify/V5E/c2_render.py`)

```
lane      = {**manifest.lane.model_dump(), 'title': <H1 minus " — report docket" from
                                            state/backups/U5.12-<slug>/tree/README.md>}
evidence  = [{'ref': f'material/{row.dest}', 'source_kind': 'local',
              'context': f'{row.bytes} bytes copied from the read-only target',
              'sha256': row.sha256} for row in manifest.material]
assemble(dock, lane=lane, claims=[c.model_dump() for c in manifest.claims],
         evidence=evidence,
         material_report=material_report_from_docket(dock, source_root=<U5.18 backup tree>),
         target_meta=manifest.target, freshness=manifest.freshness,
         source_root=<U5.18 backup tree>, generated_at=GEN)
```

A fixed `generated_at` is used so that pass-1 and pass-2 differ only in the ways the
assembler genuinely differs (HISTORY.md append, ITEM.md.rN rotation).

## Safety

* New backup generation `state/backups/U5.18-<slug>/tree/` taken first.
* The pass is first run on a **copy** (`state/verify/U5.18/dry/<slug>`); the real docket is
  touched only if every dry check is clean.
* The bare pass runs on a **copy** of the real post-pass docket
  (`state/verify/U5.18/bare/<slug>`) — it is a stability proof, not a second re-render.
* Harness: `state/verify/U5.18/rerender.py`; raw output `state/verify/U5.18/result.json`,
  `run.log`.
