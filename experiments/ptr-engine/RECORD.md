## 1. What the engine is, and its measured ratio

A Python package (Python 3.11+, executed on CPython 3.14.4, no third-party dependency) that compiles a turn's material into a **12-line index plus bodies in a content-addressed store**, so the prompt carries references instead of bytes. The model resolves a reference through one `fetch` tool; the host never re-sends a body it already sent.

**C1 — SGLang avalanche magnitude. Believed: BILL-AUDIT.** MISS-LAW/ENGINE-R1 recorded `cached=null` and billed the whole prefix (`uncached=8013 = P1+13`, `experiments/miss-law/LAW.md:85`; ENGINE-R1 cell C `397 = P1+13`, "26x"). The "5.2× overstatement" clause above is therefore WITHDRAWN: 397 is the engine's own law value (`measure/rows.jsonl:law_uncached_measured_L`), and the one second instrument on this path reports warm values in 9/12 `measure/rows.jsonl` rows — 384 ×3 cell B, 320 ×3 cell A, 320 ×3 cell D — and null only at cell C (residue 0), `quality/rows.jsonl`'s 48 request rows carry no `cached_tokens` key at all, and `run_cells.py:109` posts `/chat/completions`, not `/generate`. **C1 reopened 2026-10-25 (RECON-ADJ-CLAIMS, from rows):** the closure premise was false — `measure/rows.jsonl` carries `cached_tokens` 320/384/320 at residues 5/2/2 in cells A/B/D with `cached_reported: true`, so a second instrument on `:8012` exists and reports warm prefixes; C1 returns to OPEN pending re-adjudication of the "5.2× overstatement" against those rows. **C1 verdict 2026-10-25 (RECON-C1, from `experiments/ptr-engine/measure/rows.jsonl`):** the warm rows reconcile with this record's own law rather than contradicting it — `cached = P1 − residue = 64·floor(P1/64)` and `uncached = residue + L` with `L = n_payload + 12 = 13`, matching all three warm cells exactly (A `18 = 5 + 13`, B `15 = 2 + 13`, D `15 = 2 + 13`). `397` is therefore **not a general law of this endpoint**: for the same append at residues 2 and 5 the true bill is 15 and 18.
