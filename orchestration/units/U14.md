## Design decision

**The head is carried through as the same objects, not rebuilt equal copies.**
`SLIDING_WINDOW`, `SUMMARISE_IN_PLACE` and `FORK` all call `_rebuild` on the retained
tail, so the folded head stops being part of the prompt — and the first two drop the
invariant root with it. `APPEND_NOTE` instead returns `[*chain, note]`: same `text`,
same `node_id`, same `parent_id`, same object. Rebuilding with identical texts would
have preserved the *byte* property while silently re-addressing every node, so the test
asserts node-id identity as well — a stronger property than the card asked for, and the
one that makes cache reuse across the compaction boundary real.

**The note is a `summary` node, not a new kind.** `KINDS` is a closed frozenset in
`nodes.py`, which is outside this unit's write paths. The note is therefore
`kind="summary"` with `appended=True` in its meta, and `[note] …` as the first line of
its text; all three are inputs to its content address, so the note's id commits to
exactly what it folded. Two notes over different folds with the same summariser output
cannot collide (asserted).

**Marker** — mirrors U13 exactly, one line, both values already sha256 addresses:

```
[note] summarises nodes through <last folded head node_id>; chain <pre-compaction chain_hash>

<canned summary>
```

**No new `RenderPolicy`, no new render branch — and that is a finding, not an omission.**
`_body_nodes` emits every non-invariant node for `POINTER`/`NAIVE_APPEND`/`POINTER_FORK`
and `_history` emits `summary` (the note's kind) for `NAIVE_MUTABLE`. So the note reaches
the prompt verbatim under all four policies, and the distinction from
`SUMMARISE_IN_PLACE` lives in `node.text` — the same lesson as U13's fork marker, where a
renderer-level fix would have confounded renderer with policy. `render.py` therefore
received a docstring section recording why no branch is needed, verified by a test
parametrised over all four `RenderPolicy` values.

**Cost, stated rather than hidden.** The append form cannot carry a token *reduction*:
`tokens_after > tokens_before` (+231 estimated tokens on this event, 20 nodes vs 19
instead of 3). It annotates the fold; it does not enforce the budget. A runner with a
fixed budget will re-compact on the next turn — that is the honest price of never
rewriting the head, and it is asserted in the equal-information test rather than
smoothed over.
