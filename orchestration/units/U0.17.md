# U0.17 — doctor: stop force-probing the known-down Occamy endpoint on every control call

**Status:** done. **Write paths:** `src/resextract/doctor.py`, `tests/test_doctor.py`, `state/logs/U0.17*`,
`orchestration/units/U0.17.md`, `orchestration/handoffs/U0.17.json`. No dashboard/state/Duval writes.

## Diagnosis
`doctor.py:86 probe_occamy()` unconditionally does `GET {base}/models` under
`httpx.Client(timeout=HTTP_TIMEOUT)` with `HTTP_TIMEOUT = 5.0` (`doctor.py:26,93`); on failure it returns
DOWN immediately (the 30 s completion probe at `doctor.py:104` is never reached while the endpoint is down).
`run_doctor` (`doctor.py:289`) probes all 7 legs with no reuse and no `force` parameter.
Control path: `dashboard/app.py:207 POST /api/control/doctor` → `layer.doctor_status(force=True)`
(`app.py:187 /api/control/rescan` likewise) → `api.py:1052` skips its `doctor_ttl` cache → `api.py:1061
doctor_mod.run_doctor()` with **no force argument**, so every leg is re-probed from scratch.
A host that DROPS port 8012 costs the full 5.0 s in that one GET (measured 5.0079 s blackhole);
refused (my env) costs 0.11 s. Verifier's ~5.6 s = 5.0 s Occamy + ~0.6 s other legs.

## Fix (in `doctor.py` — the re-probing is doctor's mechanism)
`web/search.py`-style negative memory: a DOWN verdict is remembered for at most `negative_ttl_s()`
(default `DEFAULT_NEGATIVE_TTL_S = 30.0`; env `RESEXTRACT_DOCTOR_NEGATIVE_TTL_S`, or `[doctor]
negative_ttl_s` in config). `reuse_down(key, force=False)` is the single site that honours force;
`force=True` never reuses. Only DOWN is remembered (never UP), and the remembered leg dict is returned
unchanged, so reuse changes *how often* we probe, never *what* we report. Staleness bound is exactly the TTL.
Applied to the Occamy leg only (`OCCAMY_CACHE_KEY`); the other six legs stay semantics-identical.

## Follow-up (not mine — `dashboard/**` is U6.6)
`api.py:1061` calls `run_doctor()` without forwarding `force`, so an operator's explicit force reaches the
api cache but not the probe layer. Forward it (`run_doctor(force=force)`) so `force` stays meaningful
end-to-end. Residual: a control call in a fresh process / after TTL expiry still pays the 5 s Occamy
timeout, and SearXNG's cold probe measured 2.2–4.8 s on the forced path.
