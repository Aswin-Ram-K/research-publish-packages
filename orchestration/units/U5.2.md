# U5.2 — Docket MANIFEST contract + assembler with hard gates

**Purpose.** Make "one lane = one folder = one publishable item" true or false:
`MANIFEST.json` (pydantic, `extra="forbid"`) + `assemble()` that renders the
whole docket folder from claims / verdicts / copied material, and refuses to
emit a docket containing an unsupported claim, a broken material reference, or
a publication type its §3.6 guards do not allow. `verify_docket()` re-reads the
manifest and checks schema, enums, provenance/evidence and on-disk sha256.

**Write paths.** `src/resextract/docket/{manifest,assemble}.py`,
`src/resextract/docket/__init__.py` (exports), `tests/test_docket_assemble.py`,
`tests/fixtures/docket-store/**`, `dockets/_smoke/**`, `state/logs/U5.2*`,
this card and the handoff.

**Hard bound.** Max 40 tool calls, no network, no Occamy, no writes into
`state/verify-docket/**`, `/home/zer0null/Duval` or read-only fixtures.
Store tables are empty (miner running concurrently), so fixtures are explicit:
a real SQLite store built from `tests/fixtures/docket-store/seed.json` plus a
real read-only source tree copied with U5.1's `Copier`.

**What was built.**

- `manifest.py` — `Lane/Target/Freshness/Claim/MaterialItem/WebSource/GeneratedBy/DocketManifest`,
  deterministic atomic `write_manifest`, `read_manifest`, `validate_manifest`
  (enum + non-empty provenance/evidence + sha256/existence of every docket-local
  reference; empty list == valid), shared ref grammar `split_ref`/`material_dest`.
- `assemble.py` — `assemble(...)` renders README/CLAIMS/EVIDENCE/RESULTS/METHOD/
  ITEM/PRIOR_ART/REFERENCES(.md/.bib)/CHECKLIST/OPEN_QUESTIONS/UPDATE_BACKLOG/
  HISTORY + `web/`, `repro/`; gates run before any byte is written, so a refusal
  leaves no `MANIFEST.json`; unknown type downgrades to `memo` and is recorded in
  the report + `HISTORY.md`; `ITEM.md` preserved as `ITEM.md.r<N>`; `HISTORY.md`
  append-only; `EVIDENCE.md` quotes the copied bytes using `EXCERPTS.md` spans;
  `RESULTS.md` only from structured `MeasuredResult`s; `material_report_from_docket()`
  reuses an existing docket's copies by reading `EXCERPTS.md`/`LINKS.md`. Plus
  `verify_docket()`.

**Evidence.** 24/24 unit tests; full suite 250 passed, 1 skipped. Live docket at
`dockets/_smoke/` (3 claims, 6 real material files, `verify_docket` ok=True) and
a live refusal naming C1 (span past EOF + fabricated graph node). Red→green:
orphan-claim and sha256 gates were reverted one at a time; both tests fail and
the pasted output is in their docstrings.

**Out of scope / next.** `ITEM.tex`/PDF rendering, §3.6 sibling-docket split
rule, web-page copying, dockets-row upsert, and wiring `verify_docket` into
`resextract status`/refresh.

**Verdict.** done.
