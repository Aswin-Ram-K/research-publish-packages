# U2.4 — Declare the real model client's producer (close the fail-closed CONFIRMS hole)

**Purpose.** `resextract/llm/occamy.py` declared no producer and no caller passed
`producer_hint`, so the assessment gate resolved every real client to `unknown`, treated it as
non-model, and capped its `CONFIRMS` at `EXTENDS`. No healthy model could reach `CONFIRMS`.
**Write paths:** `src/resextract/llm/occamy.py`, `tests/test_occamy_producer.py`,
`tests/test_occamy_client.py` (untouched), `state/logs/U2.4*`, `orchestration/units/U2.4.md`,
`orchestration/handoffs/U2.4.json`. **Bound:** ≤22 tool calls, zero live LLM calls, mocked transport only.

**Mechanism (deliberate).** A `producer` property on `OccamyClient` computed from a class-level
`makes_requests: bool = True` flag (plus `is_replay`/`is_stub` shorthands). Chosen over
`producer_hint` because the hint path in `_client_producer` returns before consulting the client,
so a caller could declare `model` for a replay client — the property ties the declaration to the
client's own request-making capability and cannot disagree with it. A request-free subclass
inherits the cap (`replay`), never the declaration.

**Evidence.** Before: real client over MockTransport → `unknown`, `may_back_model_claim=False`,
verdict `EXTENDS` (capped, 1 real request). After: → `model`, predicate `True`, verdict `CONFIRMS`,
`evidence_ids=[7]`, `client_producer=model`, `model_calls=1`. Caps hold for undeclared / replay
subclass / fixture / model-without-requests. Vocabulary `model|replay|fixture|unknown` unchanged,
wrong case rejected with `ProducerDeclarationError`.

**Red→green.** (a) removing the declaration → `test_real_client_declares_model` and
`test_confirms_end_to_end_through_gate` fail (`'unknown' == 'model'`). (b) making `producer`
unconditional → `test_model_declaration_requires_requests` fails (`'model' != 'model'`). Both
sha256-recorded and restored bit-identically. Model path remains UNVERIFIED (endpoint down, HTTP 000).
