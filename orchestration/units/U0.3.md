# U0.3 — store + journal + doctor + real CLI

**Batch:** 0 · **Status:** done · **Author unit:** U0.3 (not the verifier)

## Purpose (one line)
Build the durable spine of `resextract`: the SQLite store, the append-only
hash-chained journal, the `doctor` dependency prober, and the real CLI dispatcher
that exposes them.

## Hard bound
Max 35 tool calls. Offline tests must not touch the network; doctor probe tests
monkeypatch the probe functions. At most one live `doctor --json` run expected,
≤2 retries, no more.

## Declared write paths
`src/resextract/store.py`, `src/resextract/journal.py`, `src/resextract/doctor.py`,
`src/resextract/cli.py`, `tests/test_store.py`, `tests/test_journal.py`,
`tests/test_doctor.py`, `state/state.sqlite`, `state/logs/U0.3*`,
`orchestration/units/U0.3.md`, `orchestration/handoffs/U0.3.json`.
**Not touched:** `src/resextract/llm/**`, `tests/conftest.py` (sibling unit U0.2), `pyproject.toml`, `config/**`.

## What landed
- **store.py** — WAL, `foreign_keys=ON`, `schema_version` + ordered migrations,
  the 11 specified tables with columns in the declared order, the four enumerated
  CHECK vocabularies (verdict / lane type / lane status / evidence source_kind),
  15 indices, typed upsert/get accessors, `set_lane_status`, `close_rework`,
  `status_json()` / `status_text()`.
- **journal.py** — one JSONL file per run at `state/journal/<run_id>.jsonl`,
  `append/read/verify` (module functions + `Journal` class), canonical-JSON
  sha256 chain, `flock`+`fsync` writes, secret-key and secret-shaped redaction
  applied before hashing, path-safe run ids.
- **doctor.py** — seven legs (Occamy, SearXNG, crawl bridge, graphify = core;
  docling bridge, renderers, dashboard port = optional), 5 s per leg / 30 s for
  the Occamy completion probe, no probe may raise, fixed-width table + `--json`,
  exit 0 iff every core leg is green else 2.
- **cli.py** — argparse dispatcher: `doctor [--json]`, `status [--json]`, and 11
  placeholders (`target run mine assess lanes materialize refresh open export
  serve watch`) that name their owning batch and exit 3.
