## Items
1. **Element type (U8.6's hole).** `nodes` was checked for non-emptiness only, so
   `nodes: [100000 ints]` was accepted (`mode=reuse, status="ok", nodes=0`).
   Fix: `_graph_unusable_reason` walks **every** element and requires a JSON object.
   Depth = all: the JSON parse is already O(len(nodes)), so the `isinstance` walk is strictly
   cheaper than the parse it rides on, and a sampled check could be gamed by a valid prefix.
   Genuine graph unaffected: all 2685 nodes are dicts → still reuses at 2685/7102.
2. **Full digest.** `_graph_digest` truncated to 12 hex, so `_same_digest` compared 12 chars:
   a wrong *tail* with the same first 12 hex reported "matches the pinned digest" (48-bit).
   Fix: `_graph_digest` returns the full 64-hex digest; `_digest12` truncates for display only;
   comparison is `min(len, 64)`. **Short-pin policy: accept-and-report** — a 12-hex pin still
   matches but adds a `PIN ABBREVIATED` run note and a `REDUCED STRENGTH` clause, because
   refusing it would force a rewrite of a committed pin for no cryptographic gain over the
   status quo. **No change to `config/graph_pin.toml` is required** — it already carries the
   full 64-hex digest.
3. **Pin failure modes.** `_graph_pin` now returns `(value, state)` where state ∈
   absent/ok/unreadable/malformed/empty/no_entry, so "never set up" is distinguishable from
   "present and broken":
   * absent → reuse, **loud** (`PIN DEGRADED` note; a fresh setup has no pin yet);
   * well-formed but no entry for this path → reuse, **loud** (absence of an expectation for
     this artifact; the file may legitimately pin other targets);
   * malformed / unreadable / empty value → **refused** (the control exists and cannot be
     honoured: corruption or interference, reported in `rejected_candidates` + notes, file kept);
   * abbreviated (<64 hex) match → **loud** `PIN ABBREVIATED`.
   `require_fresh_graph` now refuses `unverified` as well as `stale` ("do not trust a graph I
   cannot vouch for" — an unvouched graph is precisely that); it stays opt-in, so the default
   (and the genuine stale-but-reused path) is unchanged.
