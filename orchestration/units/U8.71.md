## Method

Messages were measured on the **live tests** with a `pytest.raises` wrapper
(`state/verify/U8.71/measure.py`) that recorded the emitted message *and* the src
raise-site line — no LLM calls, no live service. Reds used the established three-legged
technique: throwaway package copies under `state/verify/U8.71/copies/{pristine,mutant}`
with import redirection proven by a conftest that logs `IMPORTED_FROM`
(`import_ok` = the path really is under the copy). Mutations are message-changing and
acceptance-neutral (same type, same refusal).

## Gotchas that cost iterations

1. `shutil.copytree(src, dst/"resextract")` nests — the copy contained
   `resextract/resextract/`, so `resextract.__file__` was `None` (namespace package).
2. `run([... "-q"])` plus pytest's own `-q` = verbosity −2, which **suppresses the
   `N passed` summary line** entirely.
3. `state/state.sqlite` and `dockets/` are resolved relative to the test file's
   `parents[1]`, so a relocated test tree cannot reproduce the run; counts were run with
   `cwd=` the workspace root and a repo-shaped scratch tree.
4. The first `cli.py` mutation broke a *later* assertion inside the very same test.
