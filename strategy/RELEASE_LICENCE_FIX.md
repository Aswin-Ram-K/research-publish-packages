# RELEASE_LICENCE_FIX — ULICFIX1

The released 29-file payload `scratch/uneutral10/package/` shipped a `COMMERCIAL.md` that described
itself as a placeholder and pointed at a file that is not in the package. Fixed by author's decision:
the file now states that **commercial licensing is available on request** — no price, no phone number,
no email address invented.

## 1. The defect, verbatim

`scratch/uneutral10/package/COMMERCIAL.md:3` and
`strategy/licence-templates/RELEASED-PIECE/COMMERCIAL.md:3` were byte-identical
(sha256 `ca86a625288ac6fd9e3ae0ca9ee2a94acf3001891e5d30f347a686a975b5b9d6`) and both read:

```
> **DRAFT — template for the author to place.** See [`../PLACEMENT.md`](../PLACEMENT.md).
```

The dead link is `../PLACEMENT.md`: the payload's 29 members are root-relative and no `PLACEMENT.md`
exists anywhere in the package tree.

## 2. The fix

Line 3 replaced in **both** files — the released copy and the template it is emitted from:

```
> **Commercial licensing is available on request.** See "How to obtain a commercial licence" below.
```

Exact diff (original template → fixed file):

```diff
--- a/COMMERCIAL.md
+++ b/COMMERCIAL.md
@@ -1,6 +1,6 @@
 # Commercial use requires a paid licence
 
-> **DRAFT — template for the author to place.** See [`../PLACEMENT.md`](../PLACEMENT.md).
+> **Commercial licensing is available on request.** See "How to obtain a commercial licence" below.
 
 This project is released under the **PolyForm Noncommercial License 1.0.0** (see `LICENSE`).
```

Rest of the file's substance kept verbatim, including the recorded-gap note and the "How to obtain a
commercial licence" section (whose channel is the published repository's issue tracker, by author
decision of 2026-10-16). **The PolyForm Noncommercial body was not touched**: `LICENSE`
sha256 `fdf6e69fd59d45154edb97d9221c95c48ced4dee90ff32f5fc2438ba62ece566` is unchanged.

COMMERCIAL.md: 3512 → 3520 bytes, sha256
`ca86a625…` → `d8762806bbbb53229345b625db77910f60f7c74b608c7f550797053da89f250c`
(both paths identical again).
