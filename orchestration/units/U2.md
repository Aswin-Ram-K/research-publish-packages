# U2 — `instrument-gate`

**Status:** running (card persisted before first live request, per unit contract §4).
**Unit shape:** author unit (7-key handoff → [`orchestration/handoffs/U2.json`](../handoffs/U2.json)).

## Purpose (one purpose)

Decide whether the Occamy cache instrument is **sound enough to make any cost claim
admissible**, by running the first live measurements: a four-check gate (G0) and a
sweep of the claimed 64-token tax law (`cached = 64 * floor(L/64)` ⟺ `uncached == L mod 64`).
Everything downstream depends on this verdict: if the instrument is not sound, no cost
claim in this project is admissible.

## G0 — the gate (all four must hold)

1. Cold request → `prompt_tokens_details` absent/null; raw `usage` archived verbatim.
2. Identical repeat → `cached_tokens > 0`, and `cached <= prompt_tokens`.
3. Streaming single-pass: TTFT and `cached_tokens` both from one request.
4. Determinism: three identical repeats return the **same** `cached_tokens`; all three reported.

**If any G0 check fails → STOP the E2 sweep, write the fail verdict, report.**

## E2 — the 64-token tax law

- Sweep `L mod 64`: a fixed instruction + salt at the front, filler of N varied sentences,
  N over a ladder from the calibration (~15 tok/sentence) until `prompt_tokens` covers ≥ 20
  distinct residues mod 64 and spans lengths ≥ 512.
- Per length: one **cold** request (fresh `make_salt`) then one **warm** (identical bytes, same salt).
- `max_tokens: 8`, `temperature: 0`, `thinking=False`, `stream=True`. **One request in flight.**
- Record `L`, `cached`, `uncached`, `residual = uncached - (L mod 64)`.
- Report: full table + distribution, `residual == 0` count, max |residual|, chunked-prefill
  (8192) explainability. Kill condition: **≥ 2 of 12+ lengths with |residual| > 32 → REFUTED.**
- Boundary: a prompt shorter than 64 tokens must never report `cached > 0`.

## Bounds (hard)

- **≤ 200 live requests** total; stop at 200 regardless. Expected ≈ 97.
- **≤ 45 minutes** wall clock.
- Retry a failed request once; **3 consecutive failures → STOP and report `blocked`** with the
  exact error. No looping.
- One request in flight at a time (`max_running_requests: 5`; concurrency corrupts TTFT).

## Locking

live request until the sweep ends; 1800 s acquisition deadline, then report `blocked`.
