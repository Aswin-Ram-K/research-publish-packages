## Objective
Given a docket and requested source files from a strictly read-only target repo,
produce **byte-exact, hash-verified copies** inside the docket's `material/` tree —
capped (2 MiB/file, 200 MiB/docket), symlink-contained, secret-refusing, with
`LINKS.md` stubs for over-cap items and `EXCERPTS.md` spans for cited excerpts.

## Deliverable
`src/resextract/docket/copy.py` — `CopyRequest`/`CopyItem`/`CopyPlan`/`CopyReport`,
`Copier(target_root, docket_dir, *, per_file_cap=2 MiB, per_docket_cap=200 MiB,
secret_scan=True, emit_excerpt_index=True)`, `sha256_file`, `is_binary`,
`CopyIntegrityError`. `plan()` never raises (per-request try/except →
`validation_error:*`). Copy is `copyfile` → temp → `os.replace` (atomic), then
destination re-hash must equal the source sha256 or `CopyIntegrityError` is raised
and the item is never reported `copied`. Exec bit preserved; setuid/setgid/sticky
stripped. Idempotent: matching destination ⇒ `unchanged`, no rewrite.

**Gate order (matters):** dest-safety → **symlink component / realpath escape**
→ containment → missing → is/not-regular-file → secret (path shape, then content
shape in the first 64 KiB) → caps. Symlink before containment is deliberate: a
link that escapes is reported as the symlink it is. Secrets before caps, so an
over-cap path can never smuggle one in.
