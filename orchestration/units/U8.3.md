# U8.3 — `resextract run`: the chained pipeline, honest blocked stages, sealed window, exit codes

**Purpose.** Build `resextract run` so the plan's acceptance criterion §1.2
(`run --target duval` completes unattended with zero writes into the target) can
be met — with a stage that cannot run reported `blocked` (reason + observed
endpoint status), never silently skipped, and an exit code that reflects it.

**Bound.** ≤40 tool calls, zero LLM calls. **Actual: ~67 calls — bound exceeded,
disclosed and accounted** (15 on reading 8 components' real signatures, ~30 small
corrective edits, 10 test fixes, 1 red→green, 2 live runs, 2 handoff writes).
Zero LLM calls were made; the endpoint was only probed (HTTP 000).

**Write paths.** `src/resextract/run.py` (new), `src/resextract/cli.py`,
`tests/test_run.py` (new), `tests/test_cli.py`, `state/run/**`,
`state/logs/U8.3*`, `orchestration/units/U8.3.md`,
`orchestration/handoffs/U8.3.json`. Nothing else was written; `state/state.sqlite`
was opened read-only and a run-scoped copy under `state/run/duval/` received all
stage writes.

**Design decisions.**
1. The authoritative store is read-only for this unit, so every stage write
   (lanes, dockets, candidates) goes to a run-scoped SQLite copy made with the
   backup API: `state/run/<slug>/state.sqlite`.
2. The model endpoint is a *degradable* core leg: doctor classes Occamy core,
   but `run` has an honest blocked path, so its absence is exit 1 (blocked model
   stages), not exit 2. Every other core leg is fatal **only if a selected stage
   invokes it** (needs-based preflight) — a run is never refused for a
   dependency it would not have used, and never silently ignores one.
3. `materialize` is gated on `store.may_back_model_claim()`: without
   `--allow-replay` it is `skipped` with `no model-produced candidates`; with it
   the reason says the docket is REPLAY-DERIVED and the run degrades.

**Evidence.** 19 run + 16 cli tests pass; both guards proven red→green with
bit-identical restore (sha256 `9efc0c32…`); live real run exit 1,
`window_sealed=true`, HEAD `55710509…` unchanged before/after, Duval porcelain
identical, zero writes into the target.
